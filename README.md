# Сервер для хранения цен криптовалют

Это сервер, который позволяет:
    зарегистрировать пользователя;
    войти в систему;
    добавлять криптовалюты в список отслеживания;
    смотреть текущие цены;
    получать историю изменения цен;
    смотреть краткую статистику по изменениям;
    удалять криптовалюты из отслеживания;
    
Автоматическое обновление цен. Сервер умеет работать в автоматическом режиме.Что делает автообновление:
- Сервер через заданные промежутки времени:
    проходит по всем отслеживаемым криптовалютам;
    получает новые цены;
    обновляет сохраненные данные;
    пополняет историю цен.
    
- Что можно настроить:
    включить или выключить автообновление;
    задать интервал обновления в секундах.
    Что можно посмотреть

- Можно получить текущие настройки:
    включено ли автообновление;
    какой установлен интервал;
    когда было последнее обновление;
    когда ожидается следующее обновление.
- Что можно запустить вручную
    Есть отдельная команда для принудительного обновления всех отслеживаемых криптовалют сразу.

Откуда сервер берет данные о криптовалютах
Сервер использует внешний сервис CoinGecko.
