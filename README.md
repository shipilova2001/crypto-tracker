# Сервер для хранения и отслеживания цен криптовалют

## Описание

Это сервер, который позволяет:

- зарегистрировать пользователя;
- войти в систему;
- добавлять криптовалюты в список отслеживания;
- смотреть текущие цены;
- получать историю изменения цен;
- смотреть краткую статистику по изменениям;
- удалять криптовалюты из отслеживания.

## Автоматическое обновление цен

Сервер умеет работать в автоматическом режиме.

### Что делает автообновление

Сервер через заданные промежутки времени:

- проходит по всем отслеживаемым криптовалютам;
- получает новые цены;
- обновляет сохраненные данные;
- пополняет историю цен.

## CRUD операции для криптовалют

Все операции требуют аутентификации через заголовок:


```json
  "cryptos": [
```

---

## Детали реализации

- Все данные должны храниться в оперативной памяти.
- Архитектура должна быть подготовлена к последующей замене памяти на базу данных.
- Каждая криптовалюта хранит историю максимум из 100 последних цен.
- Цены обновляются каждые 30 секунд в фоновом потоке.
- Пароли должны быть хешированы (`bcrypt`, `scrypt`).
- Для аутентификации используются JWT токены.

## Источник данных о криптовалютах

Сервер использует внешний сервис **CoinGecko**.

Он нужен для:

- получения информации о криптовалютах;
- получения текущих цен;
- сопоставления тикера криптовалюты с внутренним идентификатором CoinGecko.

### Особенность CoinGecko

CoinGecko использует уникальные ID вместо тикеров:

- `BTC` → `bitcoin`
- `ETH` → `ethereum`
- `DOGE` → `dogecoin`

Поэтому сервер при работе с криптовалютами сначала сопоставляет тикер с ID, а затем получает данные по нужной монете.
